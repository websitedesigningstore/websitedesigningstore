# Icon sources

**Simple Icons v16.34.0** (CC0 1.0, <https://simpleicons.org>), used as inline paths in `stack.svg` and `connect.svg`:
php, mysql, python, html5, css, javascript, typescript, react, cplusplus, android, kotlin,
openjdk (shown as "Java"), espressif (shown as "ESP32"), mqtt, github, googlechrome, googleplay.

Very dark brand colours (GitHub, OpenJDK, Google Play, MQTT) are lightened so they stay visible on the navy background.
Simple Icons has no VS Code mark, so the VS Code Marketplace card uses a generic puzzle-piece glyph drawn for this
profile. The globe and newspaper glyphs are original too. Brand names and logos belong to their owners.

# Fonts

Barlow Medium, Barlow Condensed ExtraBold and JetBrains Mono (weight 500). All three are under the SIL Open Font License 1.1
(see the OFL-*.txt files). They are subset to Latin and embedded as base64 WOFF2.
